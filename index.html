آن لائن — تمام ڈیٹا کلاؤڈ پر محفوظ
پہلی بار سیٹ اپ — آن لائن ڈیٹا بیس بنائیں
یہ پورٹل اب آپ کے اپنے Google Drive فولڈر سے، ایک مفت Google Apps Script کے ذریعے، آن لائن کام کرتا ہے (Firebase کی بجائے) — نہ کوئی VPS، نہ کوئی کارڈ۔ سپروائزر، ڈسٹرکٹ آفس، ڈویژن اور ایڈمن پہلے کی طرح اپنے اپنے موبائل یا کمپیوٹر سے، انٹرنیٹ کے ذریعے، اپنی آئی ڈی سے لاگ ان ہو کر ماتحتوں کا ریکارڈ دیکھ اور اپڈیٹ کر سکیں گے۔ اسے استعمال کرنے سے پہلے ایک بار (مفت) سیٹ اپ کرنا ضروری ہے۔
  1. Google Drive میں ایک فولڈر بنائیں (یا پہلے سے بنایا ہوا استعمال کریں) اور اس کی Folder ID نوٹ کر لیں۔
  2. script.google.com پر جا کر ایک نیا Apps Script پراجیکٹ بنائیں اور ساتھ دی گئی Code.gs فائل کا کوڈ پیسٹ کریں۔
  3. کوڈ میں اپنی Folder ID اور ایک لمبی رینڈم API_KEY بھریں۔
  4. Deploy → New deployment → Web app سے ڈیپلائے کریں (Execute as: Me, Who has access: Anyone) اور جو لنک ملے اسے کاپی کریں۔
  5. یہ HTML فائل کسی ٹیکسٹ ایڈیٹر میں کھولیں، BACKEND_URL اور API_KEY والا حصہ ڈھونڈیں اور اپنی ویلیوز سے بدل کر فائل محفوظ کر لیں۔
  6. فائل کو دوبارہ براؤزر میں کھولیں — سیٹ اپ مکمل ہو جائے گا۔
مکمل، قدم بہ قدم ہدایات کے لیے ساتھ دی گئی AppsScript-Setup-Guide فائل دیکھیں۔
